A few terms come up everywhere in LightMove.ai.

**Agent**
: A voice assistant with a job, a voice and a set of rules. Each agent has its own workflow and deployments.

**Workflow**
: The steps an agent follows during a call: the greeting, the questions it asks, the decisions it makes and how the call ends. You can edit every step in the builder.

**Tools**
: Actions an agent can take during a call, such as checking a calendar, writing to a spreadsheet or calling a webhook.

**Deployment**
: Where callers reach the agent: a phone number, a SIP trunk or the web widget on your site.

**Run**
: One conversation. Each run is logged with a recording, transcript and summary so you can review what happened.

**Transfer**
: Handing the call to a person, with the context of what has been said so far.
